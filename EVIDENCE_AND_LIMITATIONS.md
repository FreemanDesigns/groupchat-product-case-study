# Evidence, Technical Scope and Privacy Boundaries

**Snapshot:** October 26, 2026

## Verified from internal documentary records

- GroupChat is a mobile-first private beta with hosted release records through **v65**.
- Recorded v63 tests: **79/79** scoped checks passed.
- Recorded v65 tests: **8/8** targeted account-help/rendered checks passed.
- Some device, affected-user and complete returning-user/cross-user acceptance is still outstanding.
- Historical GitHub code and the latest hosted app source have **not** been shown to be identical or fully reproducible from the default branch.
- Selected issue statuses displayed on the external portfolio are an **illustrative sanitized reconstruction**, not an original Jira export.

## Not claimed

No fabricated adoption, conversion, retention, customer revenue, full security certification, native app-store launch, engineering-team management experience, solo development authorship or full product acceptance.

## Safety and source-of-truth rules

This public-facing folder must never include beta-user personal data, account recovery material, real messages, production code/configuration, private invitation links, access tokens, employer-confidential artifacts or a private issue-board export.

This file is a **case-study disclosure**, not an engineering audit or security certification. Application code is deliberately excluded. The private GitHub development repository remains private. Release deployment, testing, acceptance and measured outcome are separate evidence states.
